# Task Logic Audit: McGurk Effect Task

## 1. Paradigm Intent

- Task: `mcgurk`
- Primary construct: audiovisual speech integration and McGurk fusion percept (`/da/`) under incongruent audiovisual pairings.
- Manipulated factors:
  - condition (`congruent`, `incongruent`, `audio_only`)
  - audiovisual syllable pairing (`A=/ba/ + V=/ga/`, `A=/ga/ + V=/ba/`, and matched controls)
- Dependent measures:
  - reported syllable (`/ba/`, `/da/`, `/ga/`)
  - reaction time for report
  - fusion rate in incongruent trials (`P(report=/da/ | incongruent)`)
- Key citations:
  - `W2061698928`
  - `W1976571557`
  - `W2104396257`
  - `W2015198688`

## 2. Block/Trial Workflow

### Block Structure

- Total blocks: `3` (human baseline), `1` (QA/sim profiles).
- Trials per block: `30` (human baseline), `12` (QA/sim profiles).
- Randomization/counterbalancing:
  - block-level condition order is generated by `BlockUnit.generate_conditions()` from configured condition list.
  - within each condition, concrete audiovisual pairings are sampled online by `Controller.build_trial()`.

### Trial State Machine

1. `fixation`
   - Onset trigger: `fixation_onset`
   - Stimuli shown: central fixation (`+`)
   - Valid keys: `[]`
   - Timeout behavior: auto-advance after jittered fixation duration
   - Next state: `av_stimulus`

2. `av_stimulus`
   - Onset trigger(s): `congruent_av_onset`, `incongruent_av_onset`, `audio_only_av_onset`
   - Stimuli shown together:
     - face + eye + nose primitives
     - mouth viseme (`mouth_ba`, `mouth_da`, `mouth_ga`, or `mouth_none`)
     - syllable audio (`audio_ba`, `audio_da`, `audio_ga`)
     - task prompt text
   - Valid keys: `[]`
   - Timeout behavior: auto-advance after fixed audiovisual presentation duration
   - Next state: `decision`

3. `decision`
   - Onset trigger(s): `congruent_decision_onset`, `incongruent_decision_onset`, `audio_only_decision_onset`
   - Stimuli shown:
     - "你听到的音节是？"
     - key mapping hint (`F=/ba/`, `J=/da/`, `K=/ga/`)
   - Valid keys: `[ba_key, da_key, ga_key]`
   - Response triggers:
     - `response_ba`
     - `response_da`
     - `response_ga`
   - Timeout trigger(s): `congruent_no_response`, `incongruent_no_response`, `audio_only_no_response`
   - Timeout behavior: proceed to timeout feedback
   - Next state: `feedback`

4. `feedback`
   - Onset trigger(s):
     - `response_recorded_fb_onset`
     - `timeout_fb_onset`
   - Stimuli shown:
     - response-recorded message with reported syllable, or
     - timeout message
   - Valid keys: `[]`
   - Timeout behavior: auto-advance after feedback duration
   - Next state: `iti`

5. `iti`
   - Onset trigger: `iti_onset`
   - Stimuli shown: fixation (`+`)
   - Valid keys: `[]`
   - Timeout behavior: auto-advance after jittered ITI
   - Next state: next trial

## 3. Condition Semantics

- Condition ID: `congruent`
  - Participant-facing meaning: auditory and visual syllable are matched.
  - Concrete stimulus realization: `audio_ba + mouth_ba`, `audio_da + mouth_da`, `audio_ga + mouth_ga`.
  - Expected percept tendency: matched report (`/ba/`, `/da/`, `/ga/` respectively).

- Condition ID: `incongruent`
  - Participant-facing meaning: auditory and visual syllable are mismatched.
  - Concrete stimulus realization: canonical McGurk pairs `audio_ba + mouth_ga` and `audio_ga + mouth_ba`.
  - Expected percept tendency: increased `/da/` reports (fusion).

- Condition ID: `audio_only`
  - Participant-facing meaning: auditory syllable without informative articulatory viseme.
  - Concrete stimulus realization: `audio_[ba|da|ga] + mouth_none`.
  - Expected percept tendency: report follows auditory syllable.

## 4. Response and Scoring Rules

- Response mapping (default):
  - `F` -> `/ba/`
  - `J` -> `/da/`
  - `K` -> `/ga/`
- Missing-response policy:
  - condition-specific timeout trigger emitted
  - trial is marked `decision_timed_out = true`
- Correctness policy:
  - no objective correctness feedback is presented (perceptual report paradigm)
- analysis fields include `matches_expected` and `fusion_da` for offline summaries
- Block/final summary metrics:
  - response rate
  - mean RT
  - reported syllable distribution
  - fusion rate in incongruent responded trials

## 5. Stimulus Layout Plan

- `av_stimulus` screen:
  - face center at `(0, 40)`
  - eyes at `(-58, 95)` and `(58, 95)`
  - nose at `(0, 52)`
  - mouth at `(0, -8)` with condition-specific viseme shape
  - prompt text at `(0, -220)`
- `decision` screen:
  - decision question at `(0, 120)`
  - key mapping hint at `(0, 40)`
- all participant-facing text uses `font: SimHei` with non-overlapping `pos` and `wrapWidth`.

## 7. Inference Log

- Decision: use canonical incongruent pairings (`A=/ba/ + V=/ga/`, `A=/ga/ + V=/ba/`) to elicit fusion.
- Why inference was required: included references discuss McGurk fusion principles and timing constraints, while exact code-level pairing lists must be explicit.
- Citation-supported rationale: `W2061698928` and `W1976571557` both characterize fusion behavior under incongruent audiovisual speech pairings.

- Decision: include an `audio_only` control condition with neutral mouth (`mouth_none`).
- Why inference was required: control implementations vary across studies.
- Citation-supported rationale: `W2104396257` and broader audiovisual speech literature support separating auditory-only and audiovisual integration effects.
