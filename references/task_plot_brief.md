# Task Plot Brief

## Task

- Title: McGurk Effect Task
- Construct: audiovisual speech integration / perceptual fusion
- Paradigm: three-choice syllable report after congruent, incongruent, or audio-only speech stimuli.

## Rows

- Congruent: auditory and visual syllables match.
- Incongruent: canonical mismatch pairs A=/ba/ + V=/ga/ or A=/ga/ + V=/ba/.
- Audio only: auditory syllable with neutral mouth cue.

## Trial Timeline

1. Fixation: 500-800 ms jittered fixation, no response.
2. AV stimulus: 1100 ms. Show face/viseme and play audio syllable, no response.
3. Decision: 1800 ms. Report heard syllable. Press F for /ba/, J for /da/, K for /ga/.
4. Feedback: 700 ms. Show response recorded or timeout.
5. ITI: 500-900 ms jittered fixation, no response.

## Notes

- Primary fusion metric is incongruent report=/da/.
- Immediate feedback indicates response status only; it is not objective correctness feedback.
